POLARIS WELLBEING WORDPRESS THEME
=================================

INSTALLATION STEPS:
-------------------
1. Download the 'polarisfullwebsite' folder.
2. Upload this folder to your WordPress installation: /wp-content/themes/
3. Log in to your WordPress Admin Dashboard.
4. Go to Appearance > Themes and 'Activate' the Polaris Wellbeing theme.

SETTING UP THE PAGES:
---------------------
You need to create the following pages in WordPress and assign their templates:

1. HOME:
   - Create a page named 'Home'.
   - Go to Settings > Reading.
   - Set 'Your homepage displays' to 'A static page'.
   - Select 'Home' for the Homepage.
   - (The theme will automatically use front-page.php for this).

2. ABOUT:
   - Create a page named 'About'.
   - In the 'Page Attributes' section (usually on the right sidebar), find 'Template'.
   - Select 'About Page'.

3. SERVICES:
   - Create a page named 'Services'.
   - Set Template to 'Services Page'.

4. PRICING:
   - Create a page named 'Pricing'.
   - Set Template to 'Pricing Page'.

5. SAFEGUARDING:
   - Create a page named 'Safeguarding'.
   - Set Template to 'Safeguarding Page'.

6. REFERRALS:
   - Create a page named 'Referrals'.
   - Set Template to 'Referrals Page'.

7. CONTACT:
   - Create a page named 'Contact'.
   - Set Template to 'Contact Page'.

8. POLICIES:
   - Create a page named 'Policies'.
   - Set Template to 'Policies Page'.

NOTE:
-----
This theme uses Tailwind CSS and Lucide Icons via CDN for ease of use in your XAMPP or live WordPress environment. No complex build tools are required.
